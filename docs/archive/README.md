# Historical documentation archive

This directory retains old implementation reports, setup guides, status summaries and one-off instructions formerly stored at the repository root.

**These are historical records, not current operating instructions.** They may describe earlier product naming, schema, security posture, features or hosting state. Do not execute their SQL or deployment steps without checking current source, migration ledger and [Production Readiness](../../PRODUCTION_READINESS.md).

The former root guides are preserved in `legacy-guides/`; links within them describe their original context.

Current sources of truth:
- Product/setup: [README](../../README.md)
- Architecture: [Architecture map](../ARCHITECTURE.md)
- Code standards: [Contributing](../../CONTRIBUTING.md)
- Agent rules: [AGENTS.md](../../AGENTS.md)
- Release gates: [Production Readiness](../../PRODUCTION_READINESS.md)
- Current docs: [Documentation index](../DOCUMENTATION_INDEX.md)
- Versioned schema: `supabase/migrations/`

Keep new implementation/release notes in current `docs/` documents, not in this archive.
